Time Complexity

O(V²) — Finding the unvisited vertex with minimum distance takes O(V) via linear search, executed V times: V × V = O(V²).

Space Complexity

O(V²) for the 6×6 adjacency matrix + O(V) auxiliary arrays for dist[], visited[], and parent[].

Academic Viva Preparation Notes

1. Why Dijkstra's Algorithm?

Dijkstra's algorithm solves the single-source shortest path problem on graphs with non-negative edge weights using a greedy strategy. Campus walkways have non-negative physical distances, making it optimal.

2. Role of the Parent Array

While dist[] stores the numerical shortest distance, parent[v] records which predecessor vertex updated v. Tracing parent[] backwards from destination to source reconstructs the exact sequence of campus turns.

3. Why Main Gate → Auditorium = 10?

Direct path via Library to Auditorium is 2 + 10 = 12 units. However, path via Main Gate (0) → Library (2) → IT Dept (1) → Canteen (3) → Auditorium (4) totals 2 + 1 + 5 + 2 = 10 units, which Dijkstra correctly identifies as the global minimum!
